    使用说明
    
    
      
      
    1. 选择或创建 Profile，每个环境独立保留登录状态。切换或关闭环境会先结束当前录制。
      2. 
      
    2. 输入网址，或打开演示页。
      3. 
      
    3. 在 Profile 下新建 Session，再点击「开始采集」。同一个 Session 可以保存多条独立采集记录。
      4. 
      
    4. 选择采集记录后点击「回放」，播放、倍速或拖动进度；回放时点击时间线事件可定位画面。已保存的样式、图片和字体从本地加载。
      5. 
      
    5. Session 和采集记录可分别归档或移入回收站；回收站支持恢复与彻底删除。删除 Profile 保留其历史录制。
      6. 
      
    6. 记录库支持按名称和创建时间筛选，也可检索全部 Profile。展开时间条件后，起止日期均包含当天。
      7. 
      
    7. 点击“多选”可批量整理 Session 与记录。选择整个 Session 会包含全部子记录，包括筛选隐藏的内容；确认框会说明范围。切换分组、Profile 或筛选会清空选择。
      8. 
      
    8. 导出 ZIP 并交给 Agent。默认差分压缩，包内说明会指导 Agent 用随附脚本还原；也可选择完整导出。
      9. 
      
    9. 在“Agent 连接”中开启本地 MCP，复制配置到客户端。授权后，Agent 可在指定 Profile 范围读取记录；操作网页还需单独申请控制权。
      10. 
      
    10. 顶部协作条始终显示操作者。点击“立即接管”后采集继续；Agent 断线只暂停仍由它负责的采集，重连不会自动恢复操作或采集。
      11. 
    
    
    
    数据保存在本地，按原值采集，不做脱敏。跨域 iframe、封闭 Shadow DOM 和画布内部内容不完整覆盖；具体范围见导出说明。
